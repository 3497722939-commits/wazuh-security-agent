================================================================
  蓝队安全分析 Agent - 启动流程手册
================================================================

从零开始到能对话，按顺序操作即可。


------------------------------------------------------------
第一步：启动 Wazuh 虚拟机
------------------------------------------------------------

方式 A（推荐）：双击桌面快捷方式
  桌面 -> "启动 Wazuh 虚拟机"

方式 B：手动启动
  1. 打开 VMware Workstation
  2. 左侧找到 wazuh-server，双击启动
  3. 等虚拟机启动完成（约 1-2 分钟）

确认虚拟机启动成功：
  - 虚拟机是后台静默运行的，没有窗口弹出
  - Wazuh 服务在虚拟机开机后自动启动，无需登录


------------------------------------------------------------
第二步：确认 Wazuh 服务正常
------------------------------------------------------------

打开浏览器，访问以下地址：

  https://192.168.174.137:443

  - 如果能看到 Wazuh 登录页面，说明 Wazuh 正常
  - 用户名：admin
  - 密码：<你的Wazuh管理密码>
  - 浏览器提示证书不安全，点"高级" -> "继续访问"

  如果打不开，等 1 分钟再试（虚拟机还在启动中）。


------------------------------------------------------------
第三步：启动蓝队 Agent 服务
------------------------------------------------------------

1. 按 Win+R，输入 cmd，回车打开命令行

2. 执行以下命令（复制粘贴）：

   cd /d D:\agent

   C:\Users\34977\AppData\Local\Programs\Python\Python313\python.exe web_app.py

3. 看到以下输出表示启动成功：

   蓝队 Agent 启动: http://localhost:8766
   INFO:     Uvicorn running on http://0.0.0.0:8766

   这个命令行窗口不要关，关了 Agent 就停了。


------------------------------------------------------------
第四步：打开浏览器对话
------------------------------------------------------------

在浏览器地址栏输入：

  http://localhost:8766

就会看到聊天界面，直接打字提问即可。

可以问的问题示例：
  - 最近有没有高危安全事件？
  - 检查一下最近的 SSH 登录失败
  - 昨天有没有异常登录？
  - 192.168.174.1 最近触发了什么告警？
  - 有没有失败登录后又成功登录的情况？
  - 最近告警概览


------------------------------------------------------------
常见问题
------------------------------------------------------------

Q: 浏览器打不开 https://192.168.174.137:443
A: 虚拟机还没启动完，或者虚拟机没启动。回到第一步。

Q: Agent 启动时报错 "WAZUH_PASSWORD 未设置"
A: 确认 D:\agent\.env 文件存在，里面有 WAZUH_PASSWORD=...

Q: 浏览器打开 http://localhost:8766 打不开
A: 确认第三步的命令行窗口还开着，没有关闭。

Q: 端口被占用 (error 10048)
A: 编辑 D:\agent\.env，把 AGENT_PORT=8766 改成别的端口，比如 8767，然后重新启动。

Q: 想停止 Agent
A: 回到命令行窗口，按 Ctrl+C。

Q: 想关闭虚拟机
A: 在 VMware Workstation 里右键 wazuh-server -> 电源 -> 关闭客户机。
